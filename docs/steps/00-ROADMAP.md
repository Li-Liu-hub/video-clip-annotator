## 里程碑

**M1 · 能登录**（02 完成后）
三种角色能登录，cookie 正确，管理员和标注员落到不同页面。此时除登录外全是空白页——正常。

**M2 · 能标片段**（05 完成后）
这是最关键的演示节点。打开任务 → 视频能播 → 拖动创建片段 → 刷新后片段还在。
到这一步，产品的核心价值已经成立。

**M3 · 闭环成立**（06 完成后）
提交后账本有记录，管理端统计页能看到数字。**到这一步题目要求的功能全部跑通。**

**M4 · 可交付**（09 完成后）
测试全绿、审计可查、文档齐全、一条命令启动。

---

## 每步的固定动作

1. 先看本节文档的「验收标准」
2. 写完代码，逐条打勾
3. 跑 `npm run build` 确认类型不炸
4. 通过后再进下一步

**不要跳步**。05 依赖 04 的任务状态，06 依赖 05 的片段数据，跳过去只会两头返工。

---

## 风险与应对

| 风险 | 概率 | 应对 |
|---|---|---|
| 时间轴拖拽比预想难 | 高 | 先做「两个输入框填起止时间」的降级版，跑通再换成拖拽 |
| 视频 Range 实现有问题 | 中 | 先用无 Range 的全量返回验证播放，再加 Range |
| Tailwind v4 类名不生效 | 中 | 卡住超过 20 分钟就退回内联 style，不纠缠 |
| 提交事务出现死锁 | 低 | `busy_timeout=5000` 已配，若仍失败检查是否有嵌套事务 |

**降级原则**：任何一步超时，先砍「视觉打磨」，保留「数据正确」。评分标准里数据正确是硬指标，视觉是加分项。
