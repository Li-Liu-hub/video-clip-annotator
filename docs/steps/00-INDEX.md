一个功能点 = 一次可独立验收的交付。做完一个，验收通过，提交，再下一个。

**不要并行**。每个功能点都建立在前一个之上，跳步只会返工。

> （`scripts/invariant-check.mjs`）。验收记录见 [`docs/REPORT.md`](../REPORT.md)。

## 每个功能点的固定流程

```
1. 读文档的「做什么」和「实现要点」
2. 写代码
3. 逐条过「验收」清单
4. git add -A && git commit -m "feat(<范围>): <功能点>"
5. 下一个
```

提交信息格式：`feat(A1): 建库表结构与触发器`。这样 `git log` 就是一份执行记录。
