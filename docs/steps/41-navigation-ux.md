# R1 · 全局导航与交互可用性

**做什么**：修复登录后“出不去、回不来、不知道自己在哪”的阻断问题，并统一主要页面的外壳、标题、按钮与操作反馈。不是重做业务，也不改任何认证、租户或账本规则。

**依赖**：B3、B4、E8a、G3、Q1、Q2。

## 当前问题

- `DELETE /api/auth/login` 已实现，但全站没有退出按钮。
- `/stats` 位于 `/admin` 布局之外：管理员进入后侧栏消失，两种角色都没有应用内返回入口。
- 管理台导航没有当前页状态；固定侧栏在窄屏挤压内容。
- 已提交任务支持只读工作台，但列表没有入口；视频列表“去建任务”仍是禁用占位。
- 领取、归还、重新打开、退回只有禁用态，没有进行中文案与可访问状态。
- 页面标题、操作区、焦点样式和表单尺寸各自漂移。

## 契约

### 1. 统一应用外壳

- 新建共享 `AppShell`，用于 `/admin/*`、`/tasks`、`/stats`。
- 管理员导航：视频、任务、统计、审计；标注员导航：我的任务、我的工作量。
- 当前栏目必须有明显样式与 `aria-current="page"`；`/admin/tasks/new` 仍高亮“任务”。
- 管理员进入统计页后仍看到同一套管理台导航；标注员进入统计页后仍看到标注员导航。
- 桌面使用侧栏，窄屏改为顶部账号区 + 可横向滚动的导航；375px 宽度下不得由外壳造成整页横向溢出。
- 外壳只接收显示所需的用户字段，不把数据库或服务端模块带进客户端 bundle。

### 2. 可见且可靠的退出

- 所有已登录页面均有退出入口，包括 `/admin/*`、`/tasks`、`/stats` 与 `/tasks/:id/work`。
- 只调用既有 `DELETE /api/auth/login`，不新增第二套登出 API。
- 原生 fetch URL 使用 `withBasePath`；`next/link` 与 router 跳转不重复加前缀。
- 请求中按钮禁用、显示“退出中…”并带 `aria-busy`，双击只发一次请求。
- 成功后 `router.replace('/login')` 并刷新服务端状态；失败留在当前页，恢复按钮并显示中文 `role="alert"` 反馈。

### 3. 返回与断链路修复

- 统计页标题上方有明确返回链接：管理员回 `/admin/tasks`，标注员回 `/tasks`。不能只依赖浏览器后退。
- 标注员本人 `submitted` 任务显示“查看标注”，进入既有只读工作台。
- 从任务列表第 N 页进入工作台后，返回仍到第 N 页；页码按既有 `parsePageParam` 口径归一，不接受任意返回 URL。
- 视频“去建任务”改为可用链接，携带视频 id；新建任务页仅当 id 存在于当前可选视频时预选，否则不预选。

### 4. 一致样式与反馈

- 新建共享 `PageHeader`，主要页面使用统一的返回区、标题、说明与右侧操作布局。
- 全局按钮与输入框补齐明显 `:focus-visible`、一致的最小高度、禁用态与 hover/active 反馈；保留现有暗色设计 token，不在组件硬编码新色值。
- 主要页面内容间距、面板圆角/边框、表格可读性统一；窄屏标题与操作区允许换行。
- 任务领取、归还、重新打开、确认退回在请求中显示对应进行中文案，并带 `aria-busy`；原有竞态守卫与状态更新语义不变。
- 统计原生 GET 表单的 action 使用 `withBasePath('/stats')`，子路径部署不能跳丢前缀。
- 尊重 `prefers-reduced-motion`，不让装饰动画影响操作。

## 易错点

- 给 `next/link` 或 `router.replace` 手动加 basePath，导致前缀重复。
- 把共享外壳做成引用服务端会话的客户端模块，拖入 `better-sqlite3`。
- 只在管理台加退出，遗漏统计或工作台。
- 用 `router.back()` 代替角色首页：直接打开统计链接时可能退出应用。
- 用任意 `returnTo` 查询参数，引入开放重定向。
- 为提高点击率把“归还/退回”做成导航；它们仍必须走原写接口。
- 只改按钮颜色，不解决导航、返回、忙态与死入口。
